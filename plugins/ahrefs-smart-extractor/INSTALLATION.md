# تعليمات التثبيت والبدء 🚀

## المحتويات 📦

تم إنشاء مشروع Chrome Extension متكامل يحتوي على:

```
ahrefs-smart-extractor/
├── src/
│   ├── content/          # Content Scripts (تعمل على صفحة Ahrefs)
│   ├── ui/               # واجهة المستخدم (React)
│   ├── background/       # Service Worker
│   ├── types/            # TypeScript types
│   └── utils/            # دوال مساعدة
├── package.json          # المكتبات المطلوبة
├── tsconfig.json         # إعدادات TypeScript
├── manifest.config.ts    # إعدادات Extension
├── README.md             # الوثائق الرئيسية
└── DEVELOPMENT.md        # دليل التطوير
```

## الخطوة الأولى: التثبيت المحلي 🔧

### 1. استخراج الملفات
```bash
unzip ahrefs-smart-extractor.zip
cd ahrefs-smart-extractor
```

### 2. تثبيت المكتبات
```bash
npm install
```

### 3. بناء الإضافة
```bash
npm run build
```

سيتم إنشاء مجلد `dist/` يحتوي على الإضافة الجاهزة.

## الخطوة الثانية: تثبيت في Chrome 🔌

### الطريقة الأولى: من مجلد المصدر (للتطوير)

1. **افتح صفحة Extensions:**
   - اكتب في شريط العنوان: `chrome://extensions/`
   - أو: اذهب إلى ☰ → More tools → Extensions

2. **فعّل وضع المطور:**
   - انقر الزر "Developer mode" بالأعلى اليسار

3. **تحميل الإضافة:**
   - انقر "Load unpacked"
   - اختر مجلد `dist/` من المشروع

4. **تأكيد التثبيت:**
   - ستظهر الإضافة في القائمة
   - ستجد أيقونتها في شريط الأدوات

### الطريقة الثانية: من ملف ZIP (للمستخدمين)

```bash
# بعد البناء
npm run package

# سينتج ملف: dist.zip
# ثم اتبع الخطوات أعلاه (الطريقة الأولى)
```

## الخطوة الثالثة: الاستخدام الأول ✨

### 1. انتقل إلى Ahrefs
- اذهب إلى https://ahrefs.com
- أي صفحة تحتوي على جدول

### 2. استخدم الإضافة:

**الخيار الأول: الزر العائم**
- ابحث عن الزر الأزرق في أسفل اليسار
- انقر عليه لفتح اللوحة

**الخيار الثاني: Hotkeys السريعة**
- اضغط: **Alt + C** لنسخ سريع
- أو: **Alt + X** لفتح اللوحة

**الخيار الثالث: من أيقونة الإضافة**
- انقر أيقونة الإضافة في شريط الأدوات
- ستفتح نافذة Popup بالخيارات

### 3. استخراج البيانات:

```
1. اختر "استخراج البيانات"
   ↓
2. حدد الأعمدة التي تريدها
   ↓
3. اضغط "نسخ إلى Excel"
   ↓
4. البيانات الآن في الحافظة
   ↓
5. الصق في Excel (Ctrl+V)
```

## الخطوة الرابعة: التطوير 👨‍💻

إذا كنت تريد تطوير الإضافة:

### 1. وضع التطوير:
```bash
npm run dev
```

هذا يعيد بناء الإضافة تلقائياً عند كل تغيير.

### 2. تحديث الإضافة في Chrome:
- افتح `chrome://extensions/`
- انقر زر "Refresh" على الإضافة

### 3. مراقبة الأخطاء:
- انقر بزر الماوس الأيمن على الصفحة
- اختر "Inspect" (فحص)
- افتح تبويب "Console"
- ستجد أخطاء وسجلات التصحيح

## استكشاف الأخطاء 🔍

### المشكلة: الإضافة لا تظهر في Chrome

**الحل:**
```bash
# تأكد من البناء الصحيح
npm run build

# تحقق من وجود مجلد dist/
ls dist/

# أعد تحميل الإضافة في Chrome
# chrome://extensions/ → Refresh
```

### المشكلة: لا يتم استخراج أي بيانات

**الحل:**
1. تحقق من وجود جدول على الصفحة
2. افتح Console (انقر يمين → Inspect → Console)
3. شاهد الأخطاء المعروضة
4. جرب صفحة Ahrefs أخرى

### المشكلة: "لم يتم العثور على جدول"

**الحل:**
- تأكد من أن الصفحة تحتوي على جدول
- قد تكون الصفحة تحتاج وقتاً للتحميل
- جرب صفحة مختلفة على Ahrefs

### المشكلة: البيانات لا تُنسخ

**الحل:**
```javascript
// في Console، جرب:
navigator.clipboard.writeText('test');
// إذا أظهرت خطأ، قد تكون مشكلة صلاحيات
```
