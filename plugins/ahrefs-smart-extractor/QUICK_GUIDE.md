# 📺 الدليل السريع - خطوة بخطوة

## الخطوة الأولى: التحضير ⚙️

### الخطوة 1: فتح المجلد
```
📁 انقر نقراً مزدوجاً على: ahrefs-smart-extractor.zip
    └─ سيفتح المجلد تلقائياً
```

```
Windows:
  💬 Shift + انقر يمين → Open PowerShell here

Mac/Linux:
  💬 انقر يمين → New Terminal at Folder
```

### الخطوة 3: تثبيت المكتبات
```bash
npm install
```
⏳ انتظر 2-3 دقائق حتى ينتهي

## الخطوة الثالثة: التثبيت في Chrome 🔌

### الخطوة 6: افتح Chrome
```
💻 اضغط Windows key + C + H
   أو اكتب في البحث: Chrome
```

### الخطوة 7: اذهب إلى Extensions
```
🔗 اكتب في شريط العنوان:
   chrome://extensions/
   
أو:
   ☰ (Menu) → More tools → Extensions
```

### الخطوة 8: فعّل Developer Mode
```
🎛️ ستجد زر في أعلى يسار الصفحة:
   "Developer mode"
   
   انقره ليصبح أزرق ✓
```

### الخطوة 9: تحميل الإضافة
```
🔘 اضغط زر: "Load unpacked"
   
   اختر المجلد: dist/
   (من مجلد ahrefs-smart-extractor)
   
   اضغط "Select Folder"
```

### الخطوة 10: تأكيد التثبيت
```
✅ ستظهر الإضافة في القائمة
✅ ستجد أيقونة في شريط الأدوات

🎉 تم التثبيت بنجاح!
```

## الخطوة الرابعة: الاستخدام 🚀

### الطريقة 1️⃣: Hotkey السريع (الأسرع!)

```
1. اذهب إلى أي صفحة في Ahrefs
   └─ يجب أن تحتوي على جدول

2. اضغط: Alt + C
   └─ الكمبيوتر: Alt + C
   └─ Mac: Option + C

3. رسالة تظهر: "تم النسخ بنجاح"

4. افتح Excel

5. اضغط: Ctrl + V (لصق)

6. البيانات موجودة! ✓
```

### الطريقة 2️⃣: من الزر العائم

```
1. اذهب إلى Ahrefs

2. ابحث عن الزر الأزرق
   └─ موجود في أسفل يسار الشاشة
   └─ فيه رمز ↓

3. انقر الزر

4. ستظهر لوحة بخيارات:
   ├─ استخراج البيانات
   ├─ نسخ إلى Excel
   └─ اختيار الأعمدة

5. اختر ما تريد

6. اتبع التعليمات على الشاشة
```

### الطريقة 3️⃣: من أيقونة الإضافة

```
1. انقر أيقونة الإضافة
   └─ في شريط الأدوات (أعلى يمين)

2. ستفتح نافذة Popup

3. اختر الخيار:
   ✓ استخراج البيانات
   ✓ نسخ Excel
   ✓ الإعدادات

4. اتبع التعليمات
```

## استكشاف الأخطاء 🔍

### المشكلة: الإضافة لا تظهر

**الحل:**
```
1. تحقق من مجلد dist/
   └─ الملفات موجودة؟

2. أعد تثبيت:
   └─ chrome://extensions/ → الإضافة → Remove
   └─ chrome://extensions/ → Load unpacked → اختر dist/

3. أعد تحميل الصفحة:
   └─ F5 في Ahrefs
```

### المشكلة: Alt+C لا يعمل

**الحل:**
```
1. تأكد من أن الصفحة تحتوي على جدول
2. انقر على الصفحة أولاً (لتركيز المؤشر)
3. جرب Alt+X لفتح اللوحة
4. شاهد F12 Console للأخطاء
```

### المشكلة: البيانات لا تُنسخ

**الحل:**
```
1. شاهد console (F12)
2. ابحث عن رسائل خطأ
3. جرب صفحة Ahrefs أخرى
4. أعد تشغيل المتصفح
```
