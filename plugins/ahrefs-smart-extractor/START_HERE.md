# 🚀 ابدأ من هنا - Ahrefs Smart Extractor

## 👋 مرحباً بك!

تم إنشاء **Chrome Extension** متكامل لاستخراج البيانات من Ahrefs بذكاء.

---

## ⚡ البدء السريع (3 دقائق فقط!)

### الخطوة 1️⃣: استخراج الملفات
```bash
unzip ahrefs-smart-extractor.zip
cd ahrefs-smart-extractor
```

### الخطوة 2️⃣: التثبيت
```bash
npm install
npm run build
```

### الخطوة 3️⃣: في Chrome
1. اكتب: `chrome://extensions/`
2. فعّل "Developer mode" (أعلى اليسار)
3. اضغط "Load unpacked"
4. اختر مجلد `dist/`

### الخطوة 4️⃣: الاستخدام
- اذهب إلى Ahrefs
- اضغط **Alt + C** (نسخ سريع)
- الصق في Excel ✓
